## 核心原则

**所有判断基于币种自身的统计分布（percentile/mean/std），不允许出现任何固定的百分比数字或固定倍数。**

唯一例外：结构性数量（如"至少 7 根 K 线"这类计数）

## 已完成的改造

### 1. DynamicBaseline 扩展 ✅

**文件**: `v3/modules/dynamic_baseline.py`

**新增统计量**:

| 类别 | 新增字段 | 用途 |
|------|---------|------|
| **ATR 系列** | atr_p25, atr_p40, atr_p60, atr_p70, atr_p75, atr_p90 | 波动率判断全百分位覆盖 |
| **成交量系列** | vol_p25, vol_p40, vol_p60, vol_p75, vol_p90 | 缩量/放量动态判断 |
| **RSI 系列** | rsi_lower2, rsi_upper2 (mean ± 2σ) | 极端超买/超卖判断 |
| **K 线实体** | body_mean, body_std, body_p60, body_p75 | 强势 K 线动态判断 |
| **高低点范围** | range_p25, range_p40, range_p60 | 区间收窄动态判断 |
| **涨跌幅** | gain_p60, gain_p80 | 强势赛道触发阈值 |
| **回踩比例** | pullback_p30, pullback_p40, pullback_p50, pullback_p75 | 场景 C/G 回踩上限动态化 |

**新增辅助函数**:
```python
get_rsi_threshold(bl, multiplier=0.5)      # 自适应 RSI 触发阈值
get_max_pullback_ratio(surge_pct, bl)      # 动态回踩上限
get_entry_buffer(false_breakout_rate, bl)  # 动态入场缓冲
```

#### 止盈改造（重大变化）

```python
# 改前：单一止盈
tp = swing_high + (entry - sl)

# 改后：分批止盈
tp1 = swing_high                  # 第一目标：前高（保守锁利）
tp2 = swing_high + risk * 0.5     # 第二目标：前高 +0.5×风险

# ws_monitor 触发逻辑：
# 到达 tp1 时平仓 60%，剩余 40% 等 tp2
# 如果 tp1 后回落超过 0.5×atr_baseline，全部平仓不等 tp2
```

## 多空对称性总结

| 多头场景 | 空头场景 | 对称性 |
|----------|----------|--------|
| 场景 A（回调入场） | 场景 E（反弹做空） | ✅ 完全对称 |
| 场景 B（蓄势突破） | 场景 F（破位做空） | ✅ 完全对称 |
| 场景 C（强势回踩） | 场景 G（强势反弹） | ✅ 完全对称 |

**对称原则**：
- 多头找支撑，空头找阻力
- 多头等回调，空头等反弹
- 多头怕超买，空头怕超卖
- 多头止损在支撑下，空头止损在阻力上
- 所有阈值使用相同的百分位体系
