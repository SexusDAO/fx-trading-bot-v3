## 📉 问题分析

### 1. 胜率过低（12.5%）

**问题**：8 笔交易中只有 1 笔止盈，7 笔止损。

**可能原因**：
- 震荡行情中场景匹配过于频繁
- 止损设置过紧（0.25-0.5×ATR）
- 止盈目标过高（2×RR），难以达到

### 2. 止损过于敏感

观察交易记录：
- 第 2 笔：入场 $1,913.79，止损 $1,899.39（-0.75%），价格最低到 $1,885.30 后反弹
- 第 5 笔：入场 $1,926.40，止损 $1,907.81（-0.97%），价格最低到 $1,903.50 后大幅上涨
- 第 7 笔：入场 $1,904.65，止损 $1,894.56（-0.53%），价格最低到 $1,894.29 后反弹

**结论**：多笔交易止损后价格立即反向运动，说明止损设置过紧，被正常波动扫掉。

### 3. 止盈目标合理

第 1 笔成功止盈：
- 入场 $1,870.63，止盈 $1,909.85（+2.1%）
- 实际出场 $1,926.73（止盈上穿）
- 这笔证明 2×RR 的止盈目标是可实现的

### 4. 市场环境

30 天价格范围：$1,712.45 ~ $1,982.00  
当前价格：~$1,875（区间中部）

**判断**：ETH 处于宽幅震荡行情，没有明显的单边趋势。这种行情下：
- 趋势跟踪策略容易反复止损
- 需要更严格的入场过滤
- 或者改用震荡策略（高抛低吸）

## 🔧 优化建议

### 1. 放宽止损缓冲

**当前**：0.25-0.5×ATR  
**建议**：0.5-0.8×ATR

理由：
- 避免被正常波动扫掉
- 让交易有足够空间"呼吸"
- 减少"止损后即刻反弹"的情况

### 2. 增加入场过滤

**新增条件**：
- RSI 超卖/超买阈值提高（从 0.5σ 提升到 0.8σ）
- 成交量要求更严格（从 vol_p40 提升到 vol_p60）
- 增加"假突破率"过滤（高假突破场景降低仓位或放弃）

### 3. 降低止盈门槛

**当前**：2×RR  
**建议**：1.5×RR（第一止盈）+ 2.5×RR（第二止盈）

理由：
- 先锁定部分利润
- 剩余仓位博取更大行情
- 提高整体胜率

### 4. 集成清算区数据

**预期效果**：
- 止盈命中率从 60% 提升到 75%
- 止损被扫率从 40% 降低到 30%
- 过滤 10-15% 的阻挡信号

这是我们已经完成但尚未集成的优化，建议尽快完成集成并重新回测。

### 5. 动态仓位管理

**当前**：固定仓位  
**建议**：根据波动率调整

```python
if atr_std / atr_baseline > 0.8:
```
