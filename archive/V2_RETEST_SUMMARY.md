## 进一步改进建议

### 1. 提高低分区间风控
```
63-68 分：
- 仓位从公式计算 → 固定 200U（上限）
- 止损从 ATR×1.5 → ATR×1.2（更紧）
- 持仓检查从 30 分钟 → 15 分钟
```

### 2. 增加"信心度"指标
```
信心度 = (评分 - 门槛) / (85 - 门槛)
- 信心度>0.8: 高信心（100% 仓位）
- 信心度 0.5-0.8: 中等（70% 仓位）
- 信心度<0.5: 低信心（50% 仓位）
```

### 3. 策略识别增加用户意图
```
如果用户已有持仓方向：
- 优先识别同向策略
- 反向策略需要更高分（+5 分）
```
