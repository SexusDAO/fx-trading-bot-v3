## 发现的系统性问题

### 🚨 问题 1: 评分系统过于宽松

**现象**: 9/10 标的触发开仓，平均评分 92.1 分

**根本原因**:
- 基础分 50 分过高
- EMA 排列 (15 分) + MACD (15 分) = 30 分，趋势行情中容易同时满足
- 缺少负向扣分机制

**建议修复**:
```python
# 调整评分权重
基础分 = 40  # 从 50 降至 40
EMA 排列 = 10  # 从 15 降至 10
MACD = 10  # 从 15 降至 10

# 增加扣分项
if RSI > 70: score -= 10  # 超买扣分
if RSI < 30: score -= 10  # 超卖扣分
if vol_ratio < 0.5: score -= 5  # 成交量萎缩扣分
```

### 🚨 问题 2: 成交量评分失效

**现象**: 所有标的成交量评分均为 0 分

**根本原因**:
- 使用"当前 K 线成交量 / 过去 10 根均量"
- 当前 K 线可能未走完，成交量天然偏低
- 阈值设置不合理（>2x 才给满分）

**建议修复**:
```python
# 使用过去 3 根 K 线均量 vs 过去 20 根均量
recent_vol = sum(volumes[-3:]) / 3
avg_vol = sum(volumes[-20:]) / 20
vol_ratio = recent_vol / avg_vol

# 调整阈值
if vol_ratio > 1.5: score += 15  # 从 2.0 降至 1.5
elif vol_ratio > 1.2: score += 10
elif vol_ratio > 0.8: score += 5
```

### 🚨 问题 3: RSI 超买未扣分

**现象**: ICNTUSDT RSI=88、STARUSDT RSI=79 仍获得高分

**风险**: 在极端超买区开仓，容易追高

**建议修复**:
```python
# RSI 评分改为双向
if 40 <= RSI <= 60:
    score += 10  # 中性区加分
elif 30 <= RSI < 40 or 60 < RSI <= 70:
    score += 5   # 边缘区加分
elif RSI > 75 or RSI < 25:
    score -= 10  # 极端区扣分
```

### 🚨 问题 4: 观察区机制未触发

**现象**: 0 个标的进入观察区 (63-69 分)

**原因**: 评分分布两极分化，要么>70 分，要么被强制跳过

**建议**:
- 降低开仓门槛至 65 分
- 或调整评分权重使分布更均匀
