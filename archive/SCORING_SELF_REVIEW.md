## 一、逻辑一致性问题

### ❌ 问题 1: EMA 排列评分矛盾

**文档内容**:
- 做多时：EMA 多排 20 分，空排 8 分
- 做空时：EMA 空排 20 分，多排 8 分

**但实际案例 BEATUSDT 显示**:
- BEATUSDT 是空单，实际大赚 54%
- EMA 排列为空排
- 但新系统评分只给 39 分（因为做空评分表也 penalize 了空排）

**矛盾点**: 
```
文档说做空时 EMA 空排应该 20 分
但实际代码中做空评分仍然 penalize 空排
导致 BEATUSDT 这种完美做空机会被跳过
```

**修复建议**: 
做空评分表中，EMA 空排应从 8 分 → 20 分

### ❌ 问题 2: RSI 评分逻辑混乱

**文档内容**:
```
趋势策略做多:
- RSI 30-45: 22 分（最佳）
- RSI <30: 20 分（超卖）

反转策略做多:
- RSI <25: 30 分（最佳）
- RSI 25-30: 25 分

**矛盾点**:
- 同一个 RSI=28，在趋势策略中得 20 分，在反转策略中得 25 分

- 策略选择本身就需要主观判断

**风险**: 
- 可以先选策略再凑分数（逆向选择）
- 缺乏策略自动识别机制

### ❌ 问题 3: MACD 阈值无普适性

**文档内容**:
```
MACD 柱 >0.005: 20 分
MACD 柱 -0.005 到 0: 14 分
MACD 柱 <-0.005: 8 分

### ❌ 问题 11: 止损设置过于僵化

**文档内容**:
```
高市值：止损 3%
中市值：止损 4%
低市值：止损 5%
```

**问题**:
- 不同波动率的币种用统一止损
- BTC 日波动 2-3%，止损 3% 可能太紧
- MEME 日波动 20-30%，止损 5% 可能太松

**更好的方案**:
```
止损 = ATR(14) × 2
- BTC ATR 约 2% → 止损 4%
- ONDO ATR 约 5% → 止损 10%
- MEME ATR 约 15% → 止损 30%
```

### ❌ 问题 12: 仓位分级跨度过大

**文档内容**:
```
63-69 分：50% 仓位
70-84 分：100% 仓位
≥85 分：150% 仓位
```

**问题**:
- 63 分和 69 分质量差异不大，但仓位差异？
- 69 分和 70 分只差 1 分，仓位从 50% → 100%（翻倍）
- 这会造成边界效应（故意把 69 分改成 70 分）

**更好的方案**:
```
仓位系数 = 0.5 + (score - 60) / 50
- 60 分：50% 仓位
- 70 分：70% 仓位
- 80 分：90% 仓位
- 90 分：110% 仓位
```
