### ✅ 2. 简化版背离检测（纯 Python）

**实现位置**: `modules/scoring.py::DivergenceDetector`

#### 底背离检测逻辑

```python
def detect_bullish_divergence(klines):
    """
    扫描近 20 根 1H K 线
    找出两个相邻低点（前后各 3 根 K 线为局部低点）
    条件：
    - 低点二价格 < 低点一价格（价格新低）
    - 低点二 MACD 柱 > 低点一 MACD 柱（MACD 未新低）
    满足 → 底背离成立，反转多单评分 +20 分
    """
```

**评分加分**:
```
无背离：5 分
弱背离（简化检测）: 15 分
强背离（自动检测）: 20-30 分（根据强度）
```

#### 顶背离检测逻辑

```python
def detect_bearish_divergence(klines):
    """
    扫描近 20 根 1H K 线
    找出两个相邻高点（前后各 3 根 K 线为局部高点）
    条件：
    - 高点二价格 > 高点一价格（价格新高）
    - 高点二 MACD 柱 < 高点一 MACD 柱（MACD 未新高）
    满足 → 顶背离成立，反转空单评分 +20 分
    """
```

**技术实现**:
1. **局部极值识别**: 前后各 3 根 K 线的最低/最高点
2. **MACD 计算**: 简化版 EMA(12) - EMA(26)
3. **背离强度**: 基于价格跌幅和 MACD 涨幅的标准化评分
